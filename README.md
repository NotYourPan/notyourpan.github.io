## Design Philosophy & Architecture

Built with a **Vercel & Linear-inspired craft aesthetic** paired with **terminal hacker typography** and **interactive micro-animations** from ReactBits.dev:

- **Matte Dark Surface**: Deep obsidian canvas (`#000000`) with high-contrast elements and precision 1px borders (`#262626`).
- **Precision Typography**: Official **Geist** font for sharp editorial reading paired with **JetBrains Mono** for terminal prompts, logs, and syntax pills.
- **Pure Vanilla Engines (Zero Bloat)**: No heavy npm bundles or bloated frameworks. All interactive effects run natively at 60-120fps with zero latency (< 50ms initial load).

## Running Locally

Because this project is built using pure standard web technologies, no build step or node package installation is required.

### Using Python:
```bash
# Clone repository
git clone https://github.com/NotYourPan/notyourpan.github.io.git
cd notyourpan.github.io

# Start local server
python -m http.server 3000
```
Open http://localhost:3000 in your browser.

### Using Node.js (npx):
```bash
npx serve .
```
